## 🎮 游戏简介

**驴唇不对马嘴** 是一款以"马与驴"为主题的AI辩论策略游戏。玩家扮演正方（马方），与AI控制的反方（驴方）展开激烈辩论。

### 游戏特色

- 🎭 **独特角色系统** - 每个辩手都有独特的性格、技能和语言风格
- 🧠 **六维能力体系** - 心态、逻辑、技巧性、口语性、攻击性、感染力
- ⚡ **技能对决** - 释放技能改变战局，每回合仅能使用一次
- 🎵 **沉浸式音效** - 马嘶与驴鸣的独特发言音效
- 🎨 **精美会议室场景** - 模拟真实辩论赛场地

## 🏛️ 游戏规则

### 阵营设定

| 阵营 | 阵营名 | 阵营色 |
|------|--------|--------|
| 🐴 正方 | 马方 | 蓝色 |
| 🫏 反方 | 驴方 | 红色 |

### 辩手配置

| 位置 | 🐴 马方 | 🫏 驴方 | 专属技能 |
|------|---------|---------|----------|
| 一辩 | 马嘶克 | 驴嘶克 | 钞能力（心态+5） |
| 二辩 | 赵高 | 赵高 | 指鹿为马（心态+3，逻辑+2） |
| 三辩 | 塞马娘 | 阿米娅 | 曼波！（口语性+5） |

### 六维数值

| 维度 | 说明 |
|------|------|
| 心态 | 稳定性与抗压能力 |
| 逻辑 | 论点逻辑严密程度 |
| 技巧性 | 辩论技巧/诡辩能力 |
| 口语性 | 表达流畅度 |
| 攻击性 | 进攻强度 |
| 感染力 | 说服力与煽动性 |

### 辩论流程（共26回合）

1. **开篇立论**（2回合）- 各自阐述立场
2. **驳论**（2回合）- 反驳对方论点
3. **质询**（4回合）- 尖锐提问
4. **自由辩论**（16回合）- 激烈交锋
5. **总结陈词**（2回合）- 最终陈述
6. **裁判判决** - 根据综合表现判定胜负

### 特殊机制：裁判对轰

当玩家败诉时，可进入**对轰环节**，与裁判进行2轮言语交锋，有机会翻盘！

## 🚀 快速开始

### 环境要求

- Python 3.8+
- 现代浏览器（Chrome、Firefox、Edge、Safari）

### 安装与运行

```bash
# 1. 进入后端目录
cd backend

# 2. 安装依赖（如需要）
pip install flask flask-cors 

# 3. 启动服务器
python server.py
```

### 访问游戏

打开浏览器访问：**http://127.0.0.1:5000**

## ⚙️ 配置说明

### LLM API配置

编辑 `backend/config.json`：

```json
{
    "api_base": "https://api.openai.com/v1",
    "api_key": "your-api-key",
    "model": "gpt-4",
    "use_simple_agents": false
}
```

- `use_simple_agents: true` - 使用预设句子（无需API）
- `use_simple_agents: false` - 调用LLM生成内容

### 角色定制

编辑 `backend/souls/` 下的 `.md` 文件可自定义角色性格、技能和发言风格。
